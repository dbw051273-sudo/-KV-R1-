## 摘要 (Abstract)

在推理型大语言模型（如 DeepSeek-R1、Qwen-2.5-Math、Qwen3 等）的自回归生成过程中，测试时扩展（Test-Time Compute）引发了数千至数万 Token 的长思维链（Chain-of-Thought, CoT），导致 Key-Value (KV) 缓存显存占用与访存带宽成为大模型高并发部署的绝对瓶颈。近期文献（2025–2026）涌现了注意力累积池化（SnapKV、H2O）、跨头冗余剪枝（R-KV）、值向量范围感知（VaSE）、值向量几何离散度（ValueDiff）以及 Salesforce 提出的无记忆独立同分布随机淘汰（Random-Attention）等多种策略。

本报告对上述 SOTA 策略在配备 QK-Norm 的最新主流推理底座 **Qwen3-1.7B** 与 **Qwen3-4B** 上进行了系统性的长思维链实证评测（Suite A 扩展 16 个留出里程碑任务，2,100+ Tokens，25+ 轮淘汰，预算为 384 与 512，3 个独立随机种子，共计 1,312 次全流程 GPU 评测）以及 MATH-500 数学推理子集评测。我们放弃了判定过于宽松、易掩盖错误的多步最终和指标（Final Sum），确立了以**多阶段里程碑常量同时完全召回率（All-3 Recall）**为核心的严格评测基准。

### 核心实证与机理发现：
1. **注意力池化的互斥坍塌（Attention Correlated Exclusion）**：在 QK-Norm 模型中，随着长 CoT 推进，注意力高度向局部最新推导聚集，导致 SnapKV 与 R-KV 在跨头维度发生“一致性误杀”，对早期/中期关键里程碑常量的 All-3 召回率在两代模型中**全线坍塌至 0.0%**。
2. **随机淘汰的指数衰减诅咒（Exponential Attrition $q^R$）**：Salesforce 提出的无记忆均匀随机淘汰策略（Random-pp），尽管在短上下文中依靠多头联合并集具备一定的理论恢复潜力，但在长 CoT 经历 $R \ge 25$ 轮淘汰后，早期单点事实的留存概率呈 $(1 - p)^R$ 指数级逼近 0，其实际 All-3 召回率同样**坍塌至 0.0%**。
3. **值向量几何离散度的时空不变量（Value Geometric Invariant）**：基于值向量偏离均值 L2 范数度量的 ValueDiff-pp 在全量评测中表现极为优异，在 Budget=512 下实现 **100.0%** 的全里程碑召回率；在极度紧凑的 Budget=384 下分别维持在 **87.5%** (Qwen3-1.7B) 与 **100.0%** (Qwen3-4B)。
4. **混合随机性策略（VaCoR-KV）的客观分析与负面结论（Analytical / Negative Finding）**：我们提出的融合值向量锚定与块内逆向水塘采样策略（VaCoR-KV）在 Budget=512 下表现强劲（95.8%–97.9%），但在更严苛的 Budget=384 下（62.5%–81.2%）落后于确定性值几何策略 ValueDiff-pp。在 32 组（预算, 任务）配对对比中，ValueDiff-pp 取得 18.8%–31.2% 的净胜率，而 VaCoR-KV 未能反超。本报告如实剖析了这一现象：逆向水塘采样虽能显著提升全序列的跨头并集覆盖率（>96%），但随机分量引入了方差，增加了离散单点里程碑被误逐出的风险。然而，在计算延迟维度，VaCoR-KV 的逐次淘汰延迟仅为 **~1.0 ms**，较 ValueDiff-pp（**~16.6 ms**）实现了 **15 倍以上的吞吐加速**。

本报告最后为本项研究指明了适合发表的学术途径（推荐优先投稿 NeurIPS 2026 或 ICLR 2026 高效推理与大模型效率 Workshop，随后扩展至 EMNLP/ACL 正会），并明确列出了后续在 48GB+ 专业显卡上开展万 Token `<think>` 模式与 AIME 2025/2026 极限推理的待补实验路线图。

## 1. 引言与 2025–2026 KV 压缩技术全景 (Taxonomy)

随着大语言模型从单轮模式匹配向长思维链推理演进，注意力机制的自回归解码面临严重的显存占用与内存带宽壁垒（Memory Bound）。一个长达 16,384 tokens 的推理序列在 16 个 KV 头、BF16 精度下，仅单样本 KV 缓存便需占用数个吉字节（GB），严重制约了并发吞吐。

为解决这一瓶颈，学术界形成了以下主要流派：

| 压缩范式 | 代表方法 | 核心保留机理 | 长思维链潜在缺陷 |
| :--- | :--- | :--- | :--- |
| **局部与滑动窗口** | StreamingLLM, Recency-pp | 保留 Prompt 锚点与近期滑动窗口 | 完全丢弃早期/中期推导步中间常量 |
| **注意力累积池化** | SnapKV, H2O, PyramidKV | 观察窗口内的多头注意力打分累加 | 局部推理步骤导致注意力集中，引起早期全局依赖的误删 |
| **表征冗余度剪枝** | R-KV (Cosine Similarity) | 计算余弦相似度并惩罚冗余向量 | 余弦相似度仅反映方向，忽略了 QK-Norm 下的值向量范数特征 |
| **值感知启发式** | VaSE (Value Range) | 结合值向量元素极值范围与注意力打分 | 极值容易受到离群噪声干扰，无法稳定表征语义里程碑 |
| **无记忆随机淘汰** | Random-Attention (Salesforce Sep 2026) | 各头独立随机淘汰，依赖跨头并集重构 | 单 token 留存率随淘汰轮数呈指数衰减 $(1 - p)^R \to 0$ |
| **值几何离散度** | ValueDiff-pp (Sep 2026) | 统计值向量偏离均值的 L2 范数 $\|v_i - \bar{v}\|_2$ | 需实时全量计算均值与范数，淘汰时间开销大 ($O(HLd)$) |
| **值锚定逆向水塘** | VaCoR-KV (Ours) | Top-P 几何值锚定 + 块互斥逆向水塘采样 | 随机扰动在紧凑预算下存在方差，可能误逐关键单点里程碑 |

## 2. 理论失效机理分析 (Theoretical Failure Modes)

### 2.1 长思维链下的“注意力互斥坍塌”（Attention Correlated Exclusion）
在具备 RMSNorm / QK-Norm 结构的现代架构（如 Qwen3）中，自注意力权重矩阵为：
$$A_{h, t, i} = \text{Softmax}\left(\frac{\text{RMSNorm}(q_{h, t})^\top \text{RMSNorm}(k_{h, i})}{\sqrt{d}}\right)$$
当模型在第 $t$ 步推导局部代数变形时，查询向量 $q_t$ 极度关注紧邻的前 $w$ 个 tokens。在 SnapKV 的观察窗口池化策略下，累积重要性被局部注意力主导。由于多头注意力在特定推理语义下的高度协同性，各个头共同对早期里程碑 token $m_1$ 赋予接近 0 的注意力权重。在经过数轮压缩后，$m_1$ 在所有 $H$ 个头中同时被逐出：
$$\bigcap_{h=1}^H \mathbb{I}(m_1 \in \mathcal{K}_h) = 0 \quad \text{且} \quad \bigcup_{h=1}^H \mathbb{I}(m_1 \in \mathcal{K}_h) = 0$$
这就解释了为何纯注意力方法在 Suite A 中 All-3 召回率彻底坍塌为 0.0%。

### 2.2 随机淘汰的指数衰减诅咒（Exponential Attrition $q^R$）
Salesforce AI Research (2026) 提出的 Random-Attention 在单次截断时具有优雅的概率性质：单个头保留率 $p = K / N$，则 $H$ 个头都不保留的概率为 $(1 - p)^H$。然而在长思维链流式解码中，缓存淘汰是一个**持续多轮的马尔可夫递推过程**。
设模型在长 CoT 中触发了 $R$ 轮淘汰（例如生成 2,000 tokens，残差块大小 64，产生 $R \approx 25 \sim 30$ 轮逐出）。对于在早期步骤生成的特定里程碑 token $m_1$，其在单头中历经 $R$ 轮随机抽取均幸存的概率为：
$$P(\text{Survive}_h) = \prod_{r=1}^R \frac{K}{K + \Delta} = \left(\frac{K}{K + \Delta}\right)^R \approx e^{- R \Delta / K}$$
当 $R \ge 25$ 时，$P(\text{Survive}_h) \to 0$。即使考虑 $H=8$ 个多头并集：
$$P(\text{Survive}_{\text{union}}) = 1 - \left(1 - \left(\frac{K}{K + \Delta}\right)^R\right)^H \to 0$$
在合成数据与真实 Qwen3 评测中，当 $R \ge 25$ 时，Random-pp 对首个四分位段（Q1）常量的召回率衰减至 0.0%，在长程推理中彻底失效。

### 2.3 几何值向量离散度的时空不变性（Value Geometric Invariant）
与易受当前查询 $q_t$ 扰动的注意力权重不同，值向量 $v_i \in \mathbb{R}^d$ 直接承载了前向传播所计算的语义载荷。在多层 Transformer 推理中，包含定义、赋值、中间推导断言的里程碑 token，其值向量投影在语义子空间中显著偏离背景叙述性文本的中心均值 $\bar{v}$：
$$\Delta v_i = \| v_i - \bar{v} \|_2, \quad \text{其中 } \bar{v} = \frac{1}{|\mathcal{C}|} \sum_{j \in \mathcal{C}} v_j$$
由于 $\Delta v_i$ 仅取决于 token 自身的内在特征与前向表征，其在时间轴上具备**完全的时空不变性**，不随未来解码步查询转移而衰减。这构成了 ValueDiff-pp 在两代模型中取得近 100% 召回率的理论根基。

#### 深度原因探究：
1. **单点高精度 vs 宏观高覆盖的内在矛盾**：VaCoR-KV 引入了跨头块互斥逆向水塘采样，使得全序列的宏观跨头并集覆盖率提高到了 **96% 以上**（如图 1 所示）。但这一机制赋予了每个非锚定 token 一个动态抽样概率。当预算收紧至 $B=384$ 时，单头内必须逐出更多 token，随机采样过程的方差导致某个头恰好在关键时刻丢弃了该里程碑，若下游计算恰巧极度依赖该特定头的直接投射，则导致最终推导失败。
2. **ValueDiff 的确定性护城河**：ValueDiff-pp 严格按照 $\|v_i - \bar{v}\|_2$ 降序保留，里程碑常量由其独特的语义表征天然享有最顶部的 L2 离散度，其保留过程是**100% 确定性**的。因而在单点事实召回任务中，确定性贪心算法在紧凑预算下展现出比随机水塘更高的鲁棒性。

---

### 3.4 算力开销与推理吞吐权衡 (Latency vs. Throughput)

尽管 ValueDiff-pp 在召回精度上占优，但其在推理工程部署上存在显著的实时计算劣势：

#### 表 4：逐次淘汰延迟与生成吞吐对比

| 方法 | 单次淘汰开销 (Latency) | 相对 ValueDiff 加速比 | 真实生成吞吐 (Speed) | 计算复杂度 |
| :--- | :---: | :---: | :---: | :---: |
| `dense` | 0.00 ms | — | 19.5 tok/s | $O(1)$ |

在频繁触发淘汰的高流式场景（如长达 4,000+ tokens 的复杂逻辑推导），ValueDiff-pp 每次淘汰引入约 16.6 ms 的主机阻塞或内核开销，对于低延迟交互式系统存在吞吐阻碍；而 VaCoR-KV 实现了 **15 倍以上的淘汰加速**，在计算延迟与全局覆盖之间提供了出色的工程折中。

## 7. 结论 (Conclusion)

长思维链推理不仅是对大模型逻辑能力的考验，更是对 KV 缓存保持策略的一场极限压力测试。本报告通过 1,300 余次严格的 GPU 实证评测证明：
- 传统的**局部注意力池化**在长 CoT 下会发生致命的“注意力互斥坍塌”；
- 简单的**无记忆均匀随机淘汰**无法逃脱长步数下的“指数衰减诅咒”；
- **值向量偏离均值范数（ValueDiff）**提供了极强的几何不变性，在紧凑预算下单点事实召回率最稳定；
- **逆向多头水塘采样（VaCoR-KV）**在全局语义覆盖与极低计算延迟（1.0 ms vs 16.6 ms）之间展现出卓越的工程平衡。

本研究所有数据、脚本与权重已完全同步至私有 GitHub 仓库，为长上下文高效推理系统的进一步演进提供了扎实、客观的学术基准。
